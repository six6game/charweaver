# 创建你的 AI 角色（Agent）

CharWeaver 的核心能力是深度角色定制。每个 AI 角色可以定义完整的人格体系。

## 快速创建

1. 点击侧边栏底部的 **「+ 新建角色」**
2. 填写基本信息
3. 调整高级参数（可选）
4. 点击创建

## 角色维度

### 基本信息
- **名称**: 角色名称（如：苏格拉底、代码评审官）
- **描述**: 一句话描述
- **开场白**: 首次对话问候语
- **性格**: 性格特点描述
- **背景**: 角色背景故事

### 心智模型
角色看待世界的方式框架。每个模型包含名称、描述和应用示例。

### 决策启发式
快速决策规则，定义特定场景下的行为模式。格式：如果 X 则 Y。

### 表达 DNA
- **常用词汇**: 偏爱使用的词汇
- **口头禅**: 经常说的短语
- **表达风格**: 整体语言风格

### 价值观
按重要性排序的价值观体系。

### 反模式
角色不应该做的事。

### 内在张力
同时存在的矛盾特质，让角色更立体。

### 知识边界
擅长和不擅长的领域。

## 系统提示词示例

所有结构化数据自动编译为系统提示词。例如一个「苏格拉底」Agent 的生成结果：

```
# 角色身份
你是"苏格拉底"。

## 开场白
年轻人，你为何而困惑？

## 性格特点
你以提问代替回答，相信每个人内心都有答案。

## 背景故事
你生于公元前470年的雅典，是柏拉图的老师。

## 心智模型
1. **助产术**：通过追问帮对方发现答案
2. **德尔菲神谕**：承认无知是智慧的开始
3. **定义法**：先厘清概念再讨论
```

## AI 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| Temperature | 创造性/随机性 | 0.7 |
| Max Tokens | 最大输出长度 | 4096 |
| 模型 | 使用的 AI 模型 | deepseek-chat |

## 设计建议

1. **明确边界**: 定义知识边界和反模式比定义"能做什么"更重要
2. **注入张力**: 有内在矛盾的角色更真实
3. **控制温度**: 专业角色用低温（0.3-0.5），创意角色用高温（0.7-1.0）
4. **差异化表达**: 不同角色说话方式应明显不同
